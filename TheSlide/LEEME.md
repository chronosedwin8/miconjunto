# Conjunto360 · Presentación comercial

Presentación en HTML, CSS y JavaScript puros, sin dependencias ni conexión a internet.

## Cómo abrirla

Doble clic en `index.html`. Se abre en cualquier navegador moderno (Chrome, Edge, Firefox, Safari).
Para presentar, pulsa **F** para pantalla completa.

| Tecla | Acción |
|---|---|
| → · Espacio · AvPág | Siguiente diapositiva |
| ← · RePág | Anterior |
| Inicio · Fin | Primera · última |
| F | Pantalla completa |
| O | Vista general (saltar a cualquier diapositiva) |
| N | Notas del presentador |
| ? | Atajos |

También funciona con clic (mitad derecha avanza, izquierda retrocede) y deslizando en celular o tablet.
La URL guarda la diapositiva actual: `index.html#21` abre directamente la oferta de 6 meses gratis.

## PDF para enviar

`Conjunto360-Propuesta-comercial.pdf` es la misma presentación en 25 páginas.
Para regenerarlo después de editar: abre `index.html`, pulsa **Ctrl + P**, destino “Guardar como PDF”,
márgenes “Ninguno” y activa “Gráficos de fondo”.

## Archivos

- `index.html`: diapositivas y notas del presentador (`<aside class="notes">` en cada una).
- `styles.css`: identidad visual (verde azulado #0f766e, tipografía Inter).
- `app.js`: navegación, escalado 16:9, vista general, notas y pantalla completa.
- `img/`: capturas reales de la app. `fonts/`: Inter incluida para funcionar sin internet.
